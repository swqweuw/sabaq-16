# COFFEELAB | Учебный проект кофейни

Полноценный локальный веб-проект на **Python 3.10+, SQLite, HTML, CSS и JavaScript**. Установка сторонних библиотек не требуется.

## Запуск

1. Установите Python 3.10 или новее.
2. Распакуйте архив в отдельную папку.
3. Откройте терминал в папке, где лежит `run.py`.
4. Выполните `python run.py` (Windows: `py run.py`).
5. В браузере откройте **http://127.0.0.1:5000/**.
6. Панель бариста: **http://127.0.0.1:5000/manager**.

SQLite создаётся при первом запуске: `instance/coffeelab.sqlite3`. Для восстановления первоначальной базы **остановите сервер, удалите файл `instance/coffeelab.sqlite3` и запустите сервер снова**. Никаких миграций для этой учебной версии нет.

## Возможности

- Каталог из шести напитков, фильтрация по категориям, поиск.
- Размеры M/L и горячая/холодная подача.
- Корзина, количество и расчёт стоимости только на сервере.
- Промокоды WELCOME10 (10%, от 1500 ₸) и STUDENT15 (15%, от 2400 ₸).
- Создание заказа с временем самовывоза и его публичным номером.
- Склад, рецептуры напитков, проверка остатков и атомарное списание ингредиентов.
- Панель бариста: очередь, изменение статуса, остатки, пополнение склада.

## Задание

Полное техническое задание и ненавязчивые подсказки находятся в файле `STUDENT_TASK.md`.

## Ограничения

Проект рассчитан на локальную учебную среду: нет авторизации панели бариста, онлайн-оплаты, отправки SMS, резервирования времени на конкретную дату. **Не открывайте порт 5000 для общего доступа в интернет.** Подключение Google Fonts требует интернета, но без него используются системные шрифты и сайт работает.
